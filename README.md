# CFI Record | EGX Voice-to-Order HITL Console (نظام تفريغ واعتماد أوامر البورصة المصرية)

نظام متكامل مبني على مبدأ **Copilot / Human-in-the-Loop (HITL)** لمعالجة وتسجيل مكالمات تنفيذ أوامر الأسهم في البورصة المصرية (EGX) وفقاً لمعايير **الهيئة العامة للرقابة المالية (FRA)** وقانون سوق رأس المال (القانون 95 لسنة 1992 ولائحته التنفيذية - المادة 268).

---

## 🚀 تشغيل النظام (Getting Started)

### 1. تشغيل المحرك الخلفي (FastAPI Backend)

المحرك متواجد في المجلد `backend/` ومثبت داخله البيئة الافتراضية `backend/venv`.

لتشغيل السيرفر المحلي:
```powershell
.\backend\venv\Scripts\python.exe .\backend\run_server.py
```
* **رابط الخدمة:** `http://127.0.0.1:8000`
* **لوحة التوثيق التفاعلية (Swagger UI):** `http://127.0.0.1:8000/docs`
* **قناة التحديث اللحظي (WebSocket):** `ws://127.0.0.1:8000/ws/broker`

لتشغيل حزمة الاختبارات الشاملة (Gherkin + FIX + FRA Vault):
```powershell
.\backend\venv\Scripts\python.exe .\backend\tests\test_backend.py
```

## 🎯 السيناريوهات المدعومة واختبارات القبول

1. **معيار القبول الأساسي (Gherkin Acceptance Criteria):**
   * مكالمة العميل: *"اشتري لي عشر تلاف ورقة في التجاري الدولي على 85 جنيه وخمسين قرش"*
   * الناتج: أمر `BUY`، سهم `COMI`، كمية `10,000`، نوع `LIMIT`، سعر `85.50`، صالح لجلسة اليوم `DAY`، نسبة ثقة $\ge 98\%$.
2. **الأوامر المركبة (Multi-Order Support - FR-05):**
   * مكالمة العميل: *"بيع خمس تلاف ورقة في طلعت مصطفى ماركت واشتري بالفلوس فوري على 7 جنيه و45 قرش"*
   * الناتج: استخراج أمرين مستقلين (أمر بيع `TMGH` بسعر السوق + أمر شراء `FWRY` ليميت 7.45).
3. **الأرقام والألفاظ العامية المصرية (FR-04):**
   * ترجمة *"أرنب"* إلى `1,000,000`، و*"نص مليون"* إلى `500,000`، و*"باكو"* إلى `1,000`، و*"ألفين"* إلى `2,000`.
4. **تصفية الاستفسارات واستبعاد الأوامر الوهمية (FR-01):**
   * تصنيف المكالمات الاستفسارية (*"هو السهم بكام؟ لو نزل لـ 5 هبقى اشتري"*) كـ `INQUIRY_ONLY` وتجنب توليد مسودات أوامر وهمية.
5. **الامتثال التشريعي والرقابي (FRA WORM Audit Vault):**
   * توليد معرّف تدقيق مرجعي فريد `Audit_Reference_ID`.
   * إنشاء رسائل بروتوكول `FIX 4.4` (NewOrderSingle `35=D`).
   * توقيع كل حركة بختم مشفر `SHA-256` وتخزينها في أرشيف غير قابل للتعديل (WORM) صالح لمدة 5 سنوات.
